# Experimentation Plan

> Module 5 · Run Effective Product Experimentation — ★ Deliverable 5

## Overview

This experiment will test whether the One-Click Compliance Checklist improves workflow completion for frontline logistics coordinators without increasing compliance errors.

## What you're testing

| Element | Detail |
|---|---|
| Hypothesis under test | The One-Click Compliance Checklist will increase coordinator workflow completion after route assignment by at least 8 percentage points within 8 weeks, without increasing compliance errors. |
| Experiment design (A/B, etc.) | A/B test with a 50/50 split. Control uses the current multi-step compliance process, while Variant uses the pre-filled One-Click Compliance Checklist. The test requires 557 users per group. |
| Primary metric | Coordinator workflow completion after route assignment. Baseline: 31%. |
| Guardrail metric | Compliance error rate must show no statistically significant increase versus control. |
| Decision rule (ship / kill / pivot) | Ship if workflow completion improves by at least 8 percentage points at p < 0.05 and the guardrail remains stable. Iterate if the result is positive but below the MDE. Investigate if compliance errors increase. Kill if the primary metric shows no improvement or moves negatively. |

## Findings & decision (after running it)

The experiment has not been run yet. Results will be reviewed only after the fixed 8-week test period.
